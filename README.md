## Что в папке

```
site/
  index.html            — собранная страница, открыть двойным щелчком для просмотра
  build.sh              — пересобирает index.html из четырёх блоков
  assets/hall/*.webp    — фотографии зала (временные, см. ниже)
  tilda/
    01-head.html        → Tilda: Настройки сайта → Ещё → HTML-код для HEAD
    02-style.css        → Tilda: обернуть в <style>…</style> и вставить в HEAD, либо блок T123
    03-body.html        → Tilda: блок T123 «HTML-код» на странице
    04-footer.html      → Tilda: Настройки сайта → Ещё → HTML-код для BODY (перед </body>)

Прайс Пушкин Екб октябрь-ноябрь 2026.docx   — исходный прайс
Пушкин_сценарий.docx                        — сценарий фильма (237 МБ, в git не попадает)
```

## Как вставить в Tilda

1. **HEAD** — скопируйте содержимое `tilda/01-head.html` в
   «Настройки сайта → Ещё → HTML-код для вставки внутрь HEAD».
2. **CSS** — там же, следом, вставьте содержимое `tilda/02-style.css`,
   обёрнутое в `<style> … </style>`.
   Все селекторы начинаются с `.pj`, поэтому со стилями Tilda они не конфликтуют.
3. **BODY** — на странице добавьте блок **T123 «HTML-код»** и вставьте в него
   содержимое `tilda/03-body.html` целиком.
4. **FOOTER** — содержимое `tilda/04-footer.html` (это уже готовый `<script>`)
   вставьте в «Настройки сайта → Ещё → HTML-код для вставки внутрь BODY».

Порядок важен: скрипт из шага 4 ищет разметку из шага 3.

### Картинки в Tilda
Файлы из `site/assets/hall/` загрузите через файловый менеджер Tilda,
затем в `03-body.html` замените относительные пути `assets/hall/22.webp`
на выданные Tilda адреса вида `https://static.tildacdn.com/…`.

## Идея дизайна

Сайт устроен как сама выставка: каждый крупный блок — **триптих** из трёх экранов,
узкий-широкий-узкий, со швом в 2 пикселя между ними. В секции «Эпизоды» триптих
залипает на экране, а десять эпизодов сменяют друг друга при прокрутке; внизу идёт
линейка времени 1799 → 1837.

Шрифты: **Prata** (русская дидона для заголовков), **Golos Text** (гротеск Paratype
для текста), **JetBrains Mono** (тайм-коды, номера сеансов, цены — как в колонках
режиссёрского сценария: КАДР № / ХРОНО / ТИТРЫ).

Палитра: чернильная ночь `#06080F`, снежная бумага `#EFEDE4`, свеча `#D9A441`,
сургуч `#9E2B20`.
