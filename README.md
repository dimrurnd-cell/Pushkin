## Как вставить в Tilda

### Шаг 1. Выложить медиа

В папке `site/assets/` 51 файл: 30 кадров эпизодов, 6 видео и 15 фотографий
зала. Их надо положить туда, откуда браузер сможет их забрать по прямой ссылке.
Файловый менеджер Tilda не подходит: он выдаёт каждому файлу случайный адрес,
и пришлось бы вручную править 51 путь.

Нужен любой хостинг с предсказуемыми адресами — GitHub Pages, Yandex Object
Storage, VPS, что угодно. Главное, чтобы папка `assets/` целиком легла по
одному адресу, например `https://ваш-хостинг.ru/pushkin/assets/ep/ep0-c.webp`.

### Шаг 2. Подставить адрес в код

```bash
cd site && bash set-assets-base.sh https://ваш-хостинг.ru/pushkin
```

Скрипт положит в `site/tilda-ready/` четыре готовых файла со всеми
переписанными путями. Копировать в Tilda нужно именно их.

### Шаг 3. Вставить в Tilda

Создайте пустую страницу без шапки и подвала Tilda — навигация и подвал
у сайта свои, иначе будет два меню.

1. **Настройки сайта → Ещё → HTML-код внутрь HEAD** — `1-head.html`
2. **Настройки сайта → Ещё → CSS-код** — `2-styles.css`, без тегов `<style>`
3. **На странице** — блок **T123 «HTML-код»**: ширина контейнера «во всю
   ширину», отступы сверху и снизу в ноль. Вставляете `3-block-T123.html` —
   там разметка и скрипт вместе.

Скрипт лежит внутри блока намеренно: поля «HTML-код внутрь BODY» есть не на
всех тарифах Tilda, а внутри T123 скрипты выполняются всегда. Разметка идёт
первой, скрипт вторым — порядок менять нельзя.

Перед вставкой откройте `tilda-ready/проверить-до-вставки.html` двойным
щелчком: это ровно то, что соберёт Tilda.

После публикации проверьте на телефоне — эпизоды там разворачиваются в
список, а липкая сцена отключается. Так задумано.

### Если чего-то не хватает в настройках

Тарифы Tilda отличаются набором полей. Рабочие обходные пути:

— **Нет поля CSS.** Возьмите `2-styles-for-head.html` и положите его в HEAD
  следом за `1-head.html`.

— **Ни поля CSS, ни длины в HEAD не хватает.** Положите
  `2-styles-for-head.html` в самое начало блока T123, перед разметкой.
  Тогда весь сайт живёт в одном блоке и ничего кроме него не нужно.

— **Блок T123 не принимает столько кода.** Разбейте на два блока T123
  подряд: в первый разметку из `tilda/03-body.html`, во второй скрипт из
  `tilda/04-footer.html`. Главное — скрипт ниже разметки.

### Шрифты

Заголовки набраны Prata, текст — Golos Text, цифры — JetBrains Mono,
все три подключаются с Google Fonts. Если в России загрузка окажется
медленной, скачайте шрифты, загрузите через **Настройки сайта → Шрифты**
и уберите строку `<link ... fonts.googleapis.com ...>` из `01-head.html`.
Без них сайт не рассыплется — запасные начертания прописаны, — но
характер потеряется.

## Идея дизайна

Сайт устроен как сама выставка: каждый крупный блок — **триптих** из трёх экранов,
узкий-широкий-узкий, со швом в 2 пикселя между ними. В секции «Эпизоды» триптих
залипает на экране, а десять эпизодов сменяют друг друга при прокрутке; внизу идёт
линейка времени 1799 → 1837.

Шрифты: **Prata** (русская дидона для заголовков), **Golos Text** (гротеск Paratype
для текста), **JetBrains Mono** (тайм-коды, номера сеансов, цены — как в колонках
режиссёрского сценария: КАДР № / ХРОНО / ТИТРЫ).

Палитра: чернильная ночь `#06080F`, снежная бумага `#EFEDE4`, свеча `#D9A441`,
сургуч `#9E2B20`.

## Генерация кадров через Hugging Face

Вместо Higgsfield используется Space `evalstate/flux1_schnell` (FLUX.1-schnell).

```bash
cd site && bash gen-images.sh assets/ep/prompts.tsv
```

Скрипт читает `assets/ep/prompts.tsv` (33 строки: имя, ширина, высота, промпт),
дёргает Gradio REST API и раскладывает `.webp` в `assets/ep/`. Уже готовые
файлы пропускает, так что запуск можно повторять — доберёт только недостающие.

Вёрстка подхватывает кадры сама: у каждого из 30 экранов в секции «Эпизоды»
стоит `data-img="assets/ep/epN-{l,c,r}.webp"`. Скрипт в футере проверяет, есть
ли файл: если есть — кадр плавно проявляется поверх процедурной заливки, если
нет — остаётся заливка. Править HTML после генерации не нужно.

**Сделано.** Все 30 кадров сгенерированы и лежат в `site/assets/ep/`.
Модель — Z-Image-Turbo (Space `mcp-tools/Z-Image-Turbo`), центральные кадры
1536×1024, боковые 1120×1440.

### Оживление кадров в видео

Space `zerogpu-aoti/wan2-2-fp8da-aoti-faster` — Wan 2.2 14B image-to-video.
Оживлены шесть центральных кадров, mp4 лежат в `site/assets/video/`:
пролог (метель и экипаж), юг (волна), Михайловское (Царевна-Лебедь),
Болдино (листопад), Натали (бал), финал (снег на Чёрной речке).

Вёрстка сама подставляет видео поверх картинки: у экрана есть `data-video`,
скрипт вставляет зацикленный беззвучный `<video>` и включает его только
в том эпизоде, который сейчас на экране. При системной настройке
«уменьшить движение» видео не подключается — остаётся неподвижный кадр.
